## HUD fonts

- `tinsel:hud_background` draws the dark box behind boss-bar HUD text: a 6 px cap on each end plus full-height fill
  glyphs with 1/2/4/8/16/32/64/128 px advances (`\uE100`–`\uE109`). Every file under
  `assets/tinsel/font/hud_background.json` and `assets/tinsel/textures/font/hud_background/` is generated by
  SovereignTinsel's `./gradlew generateHudAssets` task; do not hand-edit them, regenerate and copy the output.
- The seven `minecraft:boss_bar` colours under `assets/minecraft/textures/gui/sprites/boss_bar/` are deliberately fully
  transparent. A HUD is rendered as a boss bar name, so the vanilla bar line would otherwise draw through the text.
  This also hides every other vanilla boss bar while the pack is enabled.
